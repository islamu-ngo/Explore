# Project Agents (Lean)

These agent files are **small** and meant to be re-read. Do **not** rely on memory.

## When to Use Agents vs Skills

- **Use agents** for multi-step or autonomous tasks (review, refactor planning, verification).
- **Use skills** for inline patterns while coding.
