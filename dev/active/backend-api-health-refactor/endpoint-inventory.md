## Classification Legend

- `anonymous-public-read`: public read endpoint; tenant/visibility/cache variance must be explicit.
- `authenticated-read`: authenticated read endpoint; no privileged mutation.
- `authenticated-write`: authenticated mutation requiring user identity and handler-level authorization where resource-scoped.
- `privileged-resource-action`: action allowed only by resource ownership/role/policy.
- `privileged-admin-action`: tenant/host admin action.
- `download-sensitive`: presigned/download endpoint; requires explicit public-object or authorization rule.
- `setup-bootstrap-sensitive`: setup secret, first-admin, or onboarding endpoint.
- `export-public-or-authenticated`: export endpoint whose visibility must match underlying resource access.
