# Backend Contract Risk Register

Last Updated: 2026-05-07 Europe/Brussels

## Purpose

This register tracks known backend/API contract and behavior risks before behavior-changing implementation begins. Backward compatibility is not required before v1.0, but every breaking change still needs an owner, test path, OpenAPI impact, and documentation path.

## Status Legend

- `Open`: known risk not yet implemented.
