# Contributing to ISLAMU Event

Welcome! We are excited to build a free, ethical, and community-sovereign event platform together. Whether you are reporting bugs, improving documentation, translating into your language, or contributing code, your help is deeply valued.

---

## Ways to Contribute

### 1. Report Bugs & Request Features
If you discover a bug or have an idea for a feature:
- Search existing [GitHub Issues](https://github.com/islamu-ngo/Event/issues) to see if it has already been reported.
- If not, open a new issue with detailed reproduction steps, environment details (Docker version, browser, OS), and logs.

### 2. Localization & Translations (Weblate)
ISLAMU Event is a multi-lingual platform designed for global communities:
- We use [Weblate](https://hosted.weblate.org/) for crowdsourced translations.
- You do not need any coding experience to help translate UI strings, emails, and documentation into Arabic, French, Urdu, Bahasa, and other languages.

### 3. Improve Public Documentation
Documentation improvements are first-class contributions:
- If you find an error, typo, or outdated instruction in our public GitBook guides, submit a PR directly against the `docs/public/` directory in our [GitHub Repository](https://github.com/islamu-ngo/Event).

### 4. Code Contributions (C#, Blazor & Infrastructure)
We welcome code contributions from community developers!
- **Getting Started with Code**: Read our [Local Development Guide](local-development.md) to run the platform locally with .NET Aspire or Docker.
- **Deep Technical Specifications**: For complete architectural rules, Clean Architecture layers, CQRS MediatR conventions, and test suites, consult the **Internal Developer Guide** in our repository:
  - 📖 **[`docs/internal/DEVELOPER_GUIDE.md`](https://github.com/islamu-ngo/Event/blob/develop/docs/internal/DEVELOPER_GUIDE.md)**
  - 📖 **[`docs/internal/CONTRIBUTING.md`](https://github.com/islamu-ngo/Event/blob/develop/docs/internal/CONTRIBUTING.md)**
  - 📖 **[`docs/internal/ARCHITECTURE.md`](https://github.com/islamu-ngo/Event/blob/develop/docs/internal/ARCHITECTURE.md)**

## Clean-Room IP & Licensing Rules

All contributions to ISLAMU Event must respect strict clean-room intellectual property and outbound licensing principles:
- **AGPL-3.0 License**: Code submitted to this repository is licensed under GNU AGPLv3.
- **No Copying Proprietary / Copyleft Code**: Never copy code, decompiled snippets, or assets from third-party proprietary or incompatible copyleft platforms.
- Review our [Clean-Room IP & Licensing Guide](clean-room-ip-and-licensing.md) before submitting code.
