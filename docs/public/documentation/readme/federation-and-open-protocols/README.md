# Federation & Open Protocols

ISLAMU Event federates selected event data through explicit AT Protocol contracts. Capability, consent, tenant policy, lexicons, and local lifecycle state remain authoritative.

## In this section

* [AT Protocol & Bluesky Jetstream](at-protocol-and-bluesky-jetstream.md) — linked-user OAuth, governed publication, CarpaNet Jetstream ingestion, cursor settlement, and tenant discovery.
* [Lexicons](lexicons.md) — vendored schemas, exact collections, representation limits, and version governance.

## Explicit limitations

The platform does not currently implement ActivityPub, WebFinger, ActivityPub inbox/outbox, first-party PDS or AppView hosting, bridges, unrestricted public social collections, runtime lexicon discovery, wildcard ingestion, or a general-purpose public protocol server.
